# Instructions for AI coding assistants

Read **[AI-HANDOFF.md](AI-HANDOFF.md)** first: what the game is, how it is
built, how to test it, the rules for changing it, the Firebase setup and the
current state. Update its "Current state" and "Change log" sections when you
finish a change.

- The owner speaks Indonesian: answer in Indonesian. In-game text stays English.
- Run `npm test` (in `steal-a-monster/`) before every commit; keep it green.
- Admin names are in `shared/names.js` and `firebase-database.rules.json` — change both.
